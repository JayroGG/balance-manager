# Model Tiers — project pointer

The tier definitions and model pools are **global**. The single source of truth lives in `~/.config/opencode/AGENTS.md` under "Model tiers".

This file exists only as a hook for **per-project overrides**. If this project ever needs different tier pools than the global ones, document the overrides here (and mirror them in `opencode.jsonc` / agent frontmatter). Otherwise leave it empty.
